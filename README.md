# Desafio técnico Java

Projeto em Java 21 que cadastra os funcionários da tabela do desafio e executa as operações pedidas: remoção, impressão formatada, aumento salarial, agrupamento por função, aniversariantes, funcionário mais velho, ordenação, total de salários e quantidade de salários mínimos.

## Requisitos

- JDK 21
- Maven

## Executar

```sh
mvn test
mvn package
java -cp target/classes domain.Principal
```

Os testes JUnit ficam em `src/test/java/teste`.
